# 云端音色创建、更新与删除（L4）

云端存储、本地素材自动托管及百炼临时空间实验已于 2026-10-17 按用户要求暂时移出计划。下述已实现流程继续使用用户自行准备的 HTTPS 链接。

当前进入核心流程稳定化，L4 高级音色管理及完整自动托管暂停扩展；本阶段的真实云端验收聚焦已有合成、下载、候选、试听与实际用量记录。本文保留已实现操作的说明，不代表继续推进 L4 扩展或自动发起操作。

2026-10-18 按用户新要求进行一次本地参考复刻实验：百炼私有临时空间以 `voice-enrollment` 获取上传凭证，`oss://` 地址配合 `X-DashScope-OssResourceResolve: enable` 真实创建北京 Flash 音色成功，查询状态 OK，另经单句授权完成真实合成。用户判定“差异仍明显，不通过”，未采用、未追加付费重试。本次只证明该组合的单次兼容性，正式应用入口仍使用下述 HTTPS 链接，未接入自动托管。

本次核对的[官方声音复刻说明](https://help.aliyun.com/zh/model-studio/voice-cloning-user-guide)明确该系列创建音色免费，合成按目标模型计费；[临时上传说明](https://help.aliyun.com/zh/model-studio/get-temporary-file-url/)规定资源有效期 48 小时。创建音色本身与临时参考的生命周期不同。实验记录及人工结论见 `out/validation/voice-core-acceptance-20261018/cloud-clone/`，核对日期 2026-10-18。

2026-10-18 补充排查：旧创建与试听的 Voice ID 一致，目标型号一致；原 MP3 两声道逐样本相同，首声道与本地单声道平均值也相同。官方“至少 5 秒”要求针对连续清晰朗读，不能用 7.584 秒文件总长代替确认；官方推荐 10～20 秒。原文件按不同能量阈值统计的高于阈值时长只有 3.28～4.30 秒，但这不是语音识别结果，不能认定为实际有效人声时长或已证明失败原因。同目录 9 份中文素材均不足 10 秒，不通过重复、补静音或未经确认的说话人拼接凑时长。补充证据在 `out/validation/voice-cloud-reference-audit-20261018/audit.json`；此项排查未上传或重新创建音色。

随后用户单独授权同一复刻音色复述“感觉耗电耗得更快了。”，真实合成及下载成功，实际输入 10／输出 24 Token，按保存价格快照换算 ¥0.000303。人工反馈“音色差异仍明显，不通过”，不采用该实验音色；两次不同文本／原句试听失败结论均保留，不自动追加调用。绑定、声道和 PCM 适配检查未发现错误，根因仍未确定；原句失败不等于已证明所有参考或该型号均不可用。人工记录见 `out/validation/voice-cloud-reference-audit-20261018/live-review.json`。

用户随后新增同一说话人的 `梅比乌斯音频1.flac`（182.70 秒），允许自主截取测试。2026-10-18 选取原文件 78.94～96.80 秒连续片段，使用首声道 PCM16 WAV，参考上限同步为 17.86 秒。新建音色 `qwen-audio-3.1-tts-flash-sc261018b-923423da8776404c9756f076c09650f4` 查询 OK，按本次新素材测试指令仅合成一次相同原句；实际输入 10／输出 35 Token，折算 ¥0.000435。参考与新试听已提供，人工结论待确认，未替换当前声音。原 FLAC 不变，仅上传片段；旧失败记录保留，正式托管仍未接入。证据见 `out/validation/voice-cloud-mobius-20261018/`。

声音库的“通义云音色”页提供“创建云端音色／查看提交记录”。当前仅适配已接入的北京 `qwen-audio-3.1-tts-flash`，沿用设置中语音合成用途的账号、凭据和 Workspace。

## 提交流程

1. 用户自行准备有使用权、公网可读的 HTTPS 参考音频链接。应用不上传本地文件，也不下载或质检该链接。链接不接受本地路径、IP 字面量、登录凭据或非 443 端口。
2. 填写 1–10 位字母／数字前缀、人民币单次预计价格、价格来源链接及核对日期。金额是用户人工快照，不代表服务商报价、免费额度或服务端费用上限。
3. 预览账号、型号、Workspace、参考域名和金额，分别确认素材使用权、服务商读取与留存规则、本次费用，才可提交一次创建。
4. 返回 Voice ID 后仍须点击“查询审核状态并关联音色”。只有现有查询链路确认目标型号匹配、状态为 OK 才会保存声音版本；未自动生成台词或替换已应用音频。

按当前官方接口发送 `voice-enrollment/create_voice`，参考语种固定中文，最大参考时长为 10 秒，关闭服务商预处理和音量归一化。服务商仍可读取整个托管文件；10 秒不是上传／下载字节限制。源文件访问、撤下与删除由用户管理，应用不承诺服务商的素材保留期限、训练用途或远程删除结果。

## 取消、重启与核对

发出请求前，原子保存 `voice-enrollment.json` 到应用设置目录，先记为结果不明，再发送一次 POST。请求期间持有实例间锁；账号／凭据修订或记录发生变化时拒绝沿用旧预览。

取消、异常、无可信 Voice ID 或响应丢失时不自动重发。取消等待不保证远端创建停止。重新启动或点击“重读提交记录”只读取本地记录，不访问网络。用户必须到原账号控制台核对结果及费用，明确确认后才能重新准备；人工核对标记不会把未知远端结果伪装为失败、退款或删除。

如果本地记录损坏或无法读取，应用保持阻止创建；人工核对按钮不能覆盖无法识别的记录。应先核对控制台结果，并从备份恢复有效记录，保留原文件用于排查。

记录保留操作 UUID、账号／型号／Workspace、URL 域名和 URL SHA-256、人工价格与来源日期、确认时间、HTTP 状态、可信返回的请求 ID／Voice ID 和服务商报告的音色数量。URL 哈希不代表音频内容指纹。完整参考 URL、签名查询参数及 API Key 不写入记录、声音库或工程。历史记录在下次预览前归档到 `voice-enrollment-history/`，通用存储清理保护当前记录和历史目录。

## 删除云端自定义音色

“通义云音色”页的“删除云端自定义音色”支持填写当前北京 Flash 型号的自定义 Voice ID。系统音色不能删除。预览仅展示当前账号、型号、Workspace 和目标 ID，不联网；必须再次完整输入 Voice ID，并确认使用权与删除影响，才执行操作。

确认后先持久化操作记录，使用当前绑定的账号查询目标详情；仅当返回的目标型号一致、状态为 OK／DEPLOYING／UNDEPLOYED 时，发送一次 `delete_voice`。账号、凭据或配置修订、实例间锁及原记录变化都会使旧预览失效。删除前查询失败或取消记为 `delete_blocked`／`delete_not_sent`，不发送删除，可重新预览。

只有 HTTP 200、有效请求 ID、空 output 和报告数量 1 均符合官方成功响应时，记为 `deleted`／`delete_acknowledged`；这表示服务商确认删除音色。响应丢失、结构异常、请求异常或发送后的取消保持结果不明，不自动重发；须到原账号控制台核对后人工解除阻止。应用重启只读取记录，不恢复删除请求。

删除无法撤销，可能影响其它工程和应用使用同一 Voice ID 的后续合成；请先停止相关生成。已有音频、本地不可变声音版本、工程快照和托管源文件保持保留，目录需重新刷新。接口确认不代表服务商的所有素材副本、训练数据或账单已删除／撤销。删除记录沿用当前记录与历史归档，不保存查询响应中的素材链接或原始错误内容，也不把接口报告的音色数量当作 Token 或推算金额。

## 更新云端音色与本地版本保护

“更新云端音色”沿用操作窗口，填写当前北京 Flash 自定义 Voice ID 和新的公网 HTTPS 参考链接。预览不联网；再次输入 ID，分别确认素材使用权及替换影响、读取与留存政策、本次费用后才执行。应用不推算 Token 或金额，不自动上传、下载或质检素材，也不承诺更新免费。

确认后复用应用级云配置变更门禁，取消并等待本账号正在运行的云任务，阻止新云任务进入；已有其它账号任务保留。检测到其它 SubCue／旧版实例或已有配置变更时拒绝更新。前次记录哈希、配置修订及实例间锁继续生效。先查询型号及有效状态，通过后才发送一次 `update_voice` 与新 URL；不把接口接受更新当作审核或音质通过。

发送更新前，按账号、型号、地域、Workspace、Voice ID 保存新的修订 UUID，并先阻止该音色生成。成功确认后允许查询并建立新版本；更新响应不明则保持阻止，需原账号控制台人工核对后解除，再重新查询。完整 URL 仅用于本次请求，记录只保留域名与 URL 哈希；查询响应和错误中的签名链接、密钥均不保存。

修订记录位于设置目录的 `voice-revisions/`，单个文件最多读取 16 KiB，不随媒体时长增长。该目录是生成身份记录，受存储清理保护，应随配置和操作历史备份；损坏时明确阻止生成，不按旧身份继续执行。取消、销毁或任务退出会等待 HTTP 结束并释放云变更门禁。

旧声音版本、工程声音快照、已生成候选及其实际 Token／金额记录保持不变，允许继续试听原有音频。旧版本再次生成、旧的生成预览和已冻结任务在派发前都会检查修订；失配时要求重新查询并选用音色。重新查询状态 OK 后建立带修订的新不可变版本，同一修订重复选用仍可复用；新声音版本 ID 进入现有输入指纹，不能误复用旧版本生成结果。

本地修订只保护通过当前配置执行并记录的更新；服务商控制台、其它应用或其它机器发起的更新不会自动同步，应重新查询核对。更新会影响其它应用使用同一 Voice ID 的后续合成，服务商的处理、收费、审核和素材留存规则仍以实际账号结果为准。

本阶段通过模拟 HTTP 验证工作流，不代表真实账号权限、收费、素材读取、远端留存或克隆音质已验收。本地素材自动托管尚未接入；本轮未执行真实更新或删除。
