## 已实现的主要行为

- 工程未命名时即可编辑、生成、试听、应用候选及导出；首次保存等待相关任务结束，可取消等待，不隐式取消生成。
- 配音默认旁白与句子覆盖分开；修改默认音色保留局部覆盖与旧音频，只使继承句的生成输入失效。文稿 v2 兼容读取 v1，保存时升级。
- 正文按句原位编辑，朗读修正与备注遵循 Enter 应用、Shift+Enter 换行、Esc 撤回；输入法组合输入受保护。搜索、状态与段落筛选不修改文稿或应用版本。
- 批量补缺校验输入及候选文件指纹，复用有效候选；批量应用默认只填空缺，显式替换先预览范围，保留人工裁切和编排。
- 当前句、候选试听、连续成稿明确标示播放来源；支持真正暂停与继续。WAV 导出先检查缺失、待应用和失效句；按句导出在所选父目录中新建输出目录。
- 字幕正文原位编辑，宽屏常驻时间属性；工程样式与新工程默认值分别修改。音频素材使用紧凑监视器。导入先选择并校验文件，再处理未保存提醒；SRT 可保留时间或仅提取正文。
- 粗剪源试听显式激活源监视器；程序定位保留用户筛选，提供清除筛选并显示定位结果的动作。
- 三模块共用全局设置窗口及分类定位。分类切换保留草稿，统一保存；本地配音引擎分别记忆路径；云端连接测试使用当前草稿，不自动保存；旧请求结果不能验证新输入。
- 清理选择使用路径稳定身份和控制器持有的确认快照。删除前复核路径、内容指纹及保护范围；模型目录、活动工程、恢复记录、试听缓存及 Worker 临时目录受保护。
- 未命名工程使用可恢复工作库；空闲 2 秒、连续编辑最长 10 秒暂存业务与字段草稿。关闭保留恢复记录；恢复校验外部修改，中断任务不自动重新发送。
- 后台任务运行可切换模块，切换暂停旧播放；继续复用现有 GPU 队列、任务取消和资源所有权。

## 验证方法

最终执行 `tools\build-windows.bat cuda`，覆盖完整 CTest、打包检查、字幕启动及粗剪启动。原生界面另用 Windows 平台插件运行，不以 offscreen 截图评价中文排版。

定向回归覆盖默认音色继承、候选复用和批量应用、人工裁切、保存等待、字段草稿恢复、外部修改冲突、设置作用域、迟到测试结果及清理预览失效。生命周期测试保留 53 次媒体打开、播放、定位、关闭循环。

性能探针使用 500 句配音、5000 条字幕，各采样 50 次。配音测量包括选择、事件处理和帧回读；设置测量等待异步内容就绪。记录实际平台和设备像素比，不将推理、模型预检或网络时间混入普通交互指标。

验收日志、原生截图和 JSON 数据保存在忽略目录 `out/validation/unified-experience-20261015/`。

## 实测结果（2026-10-15）

- 最终 `tools\build-windows.bat cuda` 成功，**34/34 CTest 通过，79.16 秒**，包含打包检查与两个启动测试。Worker 修复后 ASR 测试组另外连续 **5/5 次通过**。
- Windows 原生界面在设备像素比 1、1.25、1.5、2 下，每档四个界面/快捷键用例全部通过。日志记录请求尺寸与实际客户区，配音包含 900×440、911×512、960×540、1092×614、1280×720、1366×768、1920×1080 等尺寸；设置覆盖五分类的小窗口。
- 缩放采用 `QT_ENABLE_HIGHDPI_SCALING=0` 配合 `QT_SCALE_FACTOR` 隔离本机系统 175% 基准，实际使用 Windows 平台插件渲染；没有更改 Windows 分辨率或系统缩放。DPI=2 时请求最大窗口超过屏幕可用高度，Windows 作客户区裁限，实际尺寸已记录；小客户区用例不受此影响。
- 500 句配音选择与帧回读 P95 为 **20.61ms**；模块切换 **31.82ms**；设置内容就绪 **121.96ms**。5000 条字幕选择 **5.79ms**、搜索 **7.03ms**。均满足本次普通交互 100ms、设置/切换 200ms 的目标。数据是本机采样结果。
- 500 句、1500 条合成候选历史压力回归通过：初次保存 153ms，含历史保存 256ms，连续预览 10.31s，导出 9.17s；试听缓存 99,231,019 字节，波形 1,024,000 字节。这些是夹具音频的编排与存储结果，不是模型合成耗时。
- 53 次媒体打开、播放、定位、关闭回归通过；预热后尾段私有内存由 96,428,032 增至 98,516,992 字节，增长约 **1.99MiB**，低于 32MiB 目标。帧缓存上限仍由现有回归检查为 128MiB。
- 实际截图复查修复了检查抽屉和字幕正文在重新挂载时的坐标残留。新增断言检查抽屉内容、页签及行内编辑区的真实可见边界，不只检查弹出状态。
- 全量回归中复现了 Worker 进程树取消的时序问题：Job 活动计数归零后，子进程句柄仍可能短暂未发出退出信号。终止前保存组内进程句柄，终止后逐一等待并关闭句柄，保留原有 Job 活动计数检查，避免取消返回时子进程尚未完成退出。
- CUDA 暂存包 **5,101,007,625 字节（4.75GiB）**，低于 4.8GiB 目标；Torch（扣除 cuBLAS）3,235,925,188 字节，cuBLAS 合计 1,080,248,544 字节，其中 Torch CUDA 12 为 572,991,488 字节、原生 CUDA 13 为 507,257,056 字节。未新增依赖或模型权重。验证后按预览流程删除本次打包暂存，保留当前构建及原有 dist；从根目录 `SubCue.bat` 启动最新构建。

本轮功能覆盖：

- **声音库与分配**：参考版本、人工审核字段、分页、停用／恢复、项目声音副本、默认旁白继承和局部覆盖。批量样本与转写流程使用隔离夹具验证，未重新运行真实 ASR 模型；人工审核不被自动结果覆盖。
- **引擎与参数**：现有本地引擎独立配置、能力驱动的语言／参数显示、缺环境时仍可编辑保存；云端仅北京 Flash 中文。参数改变使旧候选失效，增益、停顿和本地裁切不改变生成输入。
- **生成与候选**：逐句／批量、缺失和失效补齐、有效音频复用、候选试听与显式应用、人工裁切冲突保护、静音拒绝与失败重试。任务完成数以实际成功保存的候选计算。
- **试听与编排**：句子／波形定位、播放暂停、连续编排、增益／停顿／裁切、缓存复用与源音频完整性检查。损坏或缺失音频在实际消费、导出和生成复用时受校验保护；候选元数据选择不等同于实时文件可读性保证。
- **保存与恢复**：未命名工作库、草稿恢复、生成期间保存等待、新编辑保护、保存／重开／另存、工程与声音资产迁移、切工程与销毁取消；源工程和未修改句受保护。
- **导出**：冻结编排的整轨 WAV、逐句导出、过期结果确认、导出取消、源文件变化和输出占用保护；失败不发布不完整文件。物理磁盘写满等全部硬件故障仍不在本轮穷尽验证范围。
- **云端账号与费用**：账号／Workspace／型号解析、系统与自定义音色筛选、缓存失效、只读试听、实际 Token 与人民币换算、用量未知停止、结果不明不自动重发、已计费下载失败的保护。创建／更新／删除现有操作使用模拟 HTTP 验证生命周期，未重新操作远端音色；高级 L4 仍暂停。
