# 时间轴与响应性修复（0.1.1）

## 操作

- 音轨底部导航条：拖动中间浏览，拖动两端缩放；浏览不移动播放头。
- 播放接近可见区域边缘时自动翻页；拖动字幕或导航条期间暂停跟随。
- 双击字幕正文编辑；字幕块中间移动位置，两端调整时长；支持撤销和重做。
- 未定位行可以拖到时间轴，也可点击“在播放头创建”。默认时长 2 秒，限制在相邻字幕之间及媒体结尾之前；不足 250ms 时提示重新放置。
- 低置信度字幕保留候选时间并标记待确认。悬停查看候选文本和对齐分数，ASR 未提供独立分数时显示未知。
- 打轴完成后先回到编辑器，不再立即写出字幕。点击“导出”查看待确认、未定位数量；待确认字幕允许导出，未定位行不会生成虚构时间段。

## 响应性

空素材或空文稿只检查内存中的必要条件。有效任务立即显示进度，再由后台检查配置、凭据和本地模型；云端模式不校验 Whisper 文件。模型校验可响应取消。

设置页先显示，再异步查询凭据和模型状态；请求序号防止旧查询覆盖新选择。既有同步查询接口保留供非界面调用使用。

进度条区分可计量阶段与不定进度阶段，显示阶段文字和耗时。取消期间明确显示“正在取消”，原字幕保留到任务成功应用。

## 诊断

日志记录预检查、识别、对齐耗时和字幕数量；界面事件循环延迟超过 200ms 时记录 `ui_event_delay_ms`。不输出凭据内容。

字幕元数据中的 `diagnosticReason` 区分：`ASR_NO_WORDS`、`ALIGNMENT_NO_LOCATION`、`ALIGNMENT_LOW_CONFIDENCE`、`ALIGNED`。本次不更换识别服务、不降低全局阈值；固定样本回归用于验证对齐，不代表真实素材的识别准确率。

## 版本

应用内版本为 0.1.1，启动日志包含 exe 路径和编译时间。发布验证记录另见本次交付目录的 `BUILD-INFO.txt` 与 `VALIDATION.txt`。
