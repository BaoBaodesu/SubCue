## 密钥与保存

- 已保存密钥只显示固定八个圆圈及状态，不回填旧值；“更换”只接受新输入。
- 新输入默认遮挡，可临时显示，失焦、窗口失活或十秒后恢复遮挡。切账号先交给后端暂存，清空前端输入框；切回只显示“待替换”。
- “取消”撤回当前输入；“撤回密钥更改”放弃已暂存的替换或删除；关闭设置选择放弃会释放全部暂存。
- 所有类别仍使用底部保存。普通设置先保存，统一云目录再独立提交；云目录失败时保留云端草稿，并明确报错，不假称跨存储原子提交。
- 删除账号、密钥和模型均需明确确认，正式删除在保存后执行。删除密钥不会吊销云端 Key。

官方模型列表获取使用当前草稿密钥，不自动保存，只发送受控官方域名的 GET 请求。仅显示可达性和模型清单，不宣称具体任务能力已经验证。请求禁止重定向、限制响应大小并支持取消；输入修改、账号切换、关闭和销毁后旧结果不得更新当前界面。所有模型名称按纯文本显示，不解释服务端提供的富文本。

窄窗口使用账号列表与详情两级浏览，宽窗口并列显示。底部保存始终可达，正文由现有设置滚动区承载。

## P0 配音使用与安全退役

1. 在“AI 云端与模型”中，为百炼北京账号添加 `qwen-audio-3.1-tts-flash`，填写 Workspace，设为语音合成用途并保存。其它 TTS 型号或地域尚未适配，会明确阻断，不按相似名称推断协议或费用。
2. 在声音库选中档案，填写系统音色或已有 Voice ID，点击“关联当前云账号”，得到新的不可变音色版本；再选择该版本用于文稿。历史云音色不能按旧凭据引用自动关联，旧版本及已有音频保留。
3. 配音工作区先预览发送文本，再确认生成；不预测 Token、金额或要求校准批次。生成后保留服务商返回的实际输入／输出 Token，按该次价格快照换算人民币金额，可在任务记录中查看。实际已知费用达到软预算后暂停后续请求，单次请求仍可能超出预算；用量未知时保留未知状态并暂停。预览后账号、模型或 Workspace 变化必须重新预览；同账号密钥轮换不使音色和已有音频失效，运行批次继续使用冻结凭据。

删除账号或密钥先经应用上下文按账号定位原任务所有者，取消并等待其退出，再提交配置与凭据删除；不取消其它账号或本地任务。有其它 SubCue／旧版实例运行、或无法确认进程状态时，阻止删除并要求正常关闭其它实例，不尝试跨进程强杀任务。
