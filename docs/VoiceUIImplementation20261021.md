# AI 配音界面与声音库改造验收

日期：2026-10-21。保留深色 Qt Basic 风格，未新增训练、专属模型导入或 Fish 后端。

## 已实施

- 三栏默认 3:4:3，支持分隔拖动、比例保存、旧布局迁移与恢复默认；窄窗口侧栏可滚动。
- 声音库统一「+ 添加音色」，内部页面导航，明确页签及列表选择态，操作区和试听条固定。
- 参考创建采用素材、确认、创建三个步骤；自动识别只产生草稿；转写和片段变更使确认失效。素材可追加、去重，取消不建立空档案。
- 复用原声音库版本与审核规则，组合提交在同一事务内建立音色、版本及默认参考；失败只删除本次新建资产。
- 训练及专属模型导入明确显示尚未接入，相关执行按钮禁用。云端添加复用既有账号、预览、确认、提交及审核能力。
- 共用播放器支持暂停、继续、停止、进度、时长、跳转、试听音量和静音；音量仅作用于试听实例。停止下载、切换工程及窗口关闭均取消相关试听。
- 引擎切换提供参考文字、语言、审核及来源兼容反馈；候选试听、应用与重新生成继续复用原有绑定和保护规则。
