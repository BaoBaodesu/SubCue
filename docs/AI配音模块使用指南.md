# AI 配音模块使用指南

本文介绍 SubCue AI 配音工作区的本地文本转语音，以及如何用本地模型创建可复用的新音色。界面名称可能随版本调整；本地音色在当前实现中是“参考音频 + 转写”的声音档案版本，并非训练出新的模型权重。

## 一、本地文本转语音

### 1. 配置并检查本地环境

1. 打开 AI 配音工作区，选择引擎：`Qwen Base · 本地`、`IndexTTS 2.5 · 本地` 或 `GPT-SoVITS · 本地`。
2. 点击“引擎配置”旁的“配置…”，进入“设置 → AI 配音”。选择对应引擎，填写 Python 环境路径和模型目录（Index/GPT 按界面要求填写包含本地权重的源码根目录），保存设置。
3. 返回工作区，展开“引擎配置”，点击“预检环境与模型”。确认检查状态成功；切换引擎或路径后需要重新预检。缺少依赖或模型时，按提示修复本机环境后再继续。

模型文件需由用户预先放在本地，按项目现有模型部署方式配置；模型权重不由配音工作区下载。

### 2. 准备文稿和音色

1. 点击“添加文稿…”输入台词，或用“导入…”载入文稿。选中需要生成的句子，检查正文及“朗读修正”内容。
2. 在左侧“音色分配”选择该引擎可用的本地音色。没有音色时点击“管理…”，在声音库添加并审核本地参考（见下文）。云端 Voice ID 不能当作本地参考使用。
3. 选定引擎后，工作区只显示该引擎已接入的参数。Qwen Base 使用已审核参考及其转写，不执行自由表演指令；Index 支持 seed、时长倍率、单类情绪和发音标注；GPT-SoVITS 支持 seed 和语速倍率，专属权重控制尚未接入。

### 3. 生成与试听

1. 在顶部“生成范围”选择当前句、当前段、全部句子、缺失或失效句，或选中句。
2. 点击“生成…”开始本地合成。可在配音任务记录中查看运行状态；需要停止时点击“取消生成”。
3. 生成后试听候选，确认效果后应用到句子。需要修改台词、音色或参数时重新生成；已有候选可能因此失效。
4. 完成后从“文件 → 导出音频…”导出成稿。导出前按提示处理缺失、未应用或已失效的句子。

## 二、使用本地模型创建新音色

这里的“创建音色”是将参考音频登记为声音档案，并由 TTS 模型在合成时参考它；不会微调或训练一个新的模型文件。

1. 在配音工作区左侧“音色分配”点击“管理…”，打开“声音库”。
2. 在左侧输入档案名称，点击“新建”，再选中新建的档案。
3. 确认右侧选择“本地参考”页签，点击“选择文件”，导入该说话人的 WAV、FLAC、MP3、M4A 或 OGG 参考音频。
4. 按界面要求填写与音频内容一致的转写。Qwen Base 和 GPT-SoVITS 的本地合成需要已审核参考及转写；请勿猜写或使用不匹配的文本。Index 的字段要求以界面显示为准。
5. 点击“保存新的参考版本”。在声音库版本列表中找到它，点击“检查并审核”，试听参考并核对转写、语言和质量信息，然后保存新的审核版本。未审核版本不能用于本地生成。
6. 回到工作区，在音色分配列表选择已审核版本，并指定应用范围（默认旁白、当前句、当前段、全部未绑定句子或选中句）。之后即可按上文生成。

同一声音档案可以保留多个参考版本；改用新参考时会建立新版本，已有音频和旧版本仍保留。参考样本的试听只是原始素材试听，不代表模型合成效果。

### 参考音频建议

选择单一说话人、清晰干净、少背景音乐和混响的语音；内容应与转写逐字一致。避免剪切字头字尾、多人混说或明显噪声。只导入你有权使用的声音素材，并遵守相关授权及隐私要求。音质和相似度取决于素材、模型及参数，不能保证与参考完全一致。

## 三、引擎差异与常见问题

- **没有可选音色**：进入声音库创建本地参考版本，并完成“检查并审核”；确认当前档案已选中。
- **本地生成提示环境未验证**：在设置检查 Python/模型路径，返回工作区重新预检；更换路径或引擎后再次检查。
- **提示参考无效或不兼容**：确认参考文件仍可读取、审核状态有效，且当前引擎要求的转写已填写。
- **切换引擎后音色不可用**：不同引擎和云端声音不能互相冒用；切换到匹配的声音版本，或为目标引擎准备合适的本地参考。
- **想生成专属模型权重**：当前工作区未接入专属音色微调训练和权重管理；本指南中的音色创建不等于训练模型。
- **Mock · 测试音**：只用于验证流程，不代表真实 TTS 音质。
